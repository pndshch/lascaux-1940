# ラスコー 1940 / Lascaux 1940 — Discovery in the Dark

**1940年9月12日**、フランスはモンティニャックの森で、4人の少年と犬のロボが、嵐で倒れた木の根もとの穴に滑り降りた。
彼らが見たのは、**17,300年**だれの目にも触れなかった洞窟壁画だった。

A torch-reveal browser game retracing the night of 12 September 1940 — when teenagers discovered the Lascaux cave paintings.

**[▷ Play](https://pndshch.github.io/lascaux-1940/)**

## 遊び方 / How to play
- 画面に指（マウス）を置いて、ランプで壁を**照らす**。
- 動物が見えてきたら、その絵について読む。
- 3つの間：**雄牛の広間 → 軸状の通路 → 井戸の場面**。

Drag a finger across the dark cave wall — the lamp reveals the paintings as you sweep. 3 chambers; about 3 minutes.

## 史実 / Historical notes
- **1940-09-12** Marcel Ravidat (18) と犬のロボが穴を見つける
- **1940-09-13** ジャック・マルサル(15)、ジョルジュ・アニェル(16)、シモン・コエンカ(15)を連れて再訪。発見
- 約 **2,000点**の絵と記号 / 馬・オーロックス・シカ・バイソン
- **1948** 一般公開 / **1963** 来場者の息と体温で藻が発生し永久閉鎖
- **1983** 複製（ラスコーII）開園 / 本物は研究者のみ
